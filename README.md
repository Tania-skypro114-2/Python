## Инструкция по запуску тестов для формирования отчета Allure

1. Перейдите в директорию с тестами:
   ```bash
   cd 10_lesson
   ```

2. Запустите тесты с генерацией отчета Allure с помощью команды:
   ```bash
   python -m pytest --alluredir allure-result
   ```

   Эта команда запустит все тесты и сохранит результаты в директорию `./allure-result`.Python

## Инструкция по просмотру сформированного отчета Allure

1. После завершения тестов, чтобы просмотреть отчет, выполните команду:
   ```bash
   allure serve allure-result
   ```

   Эта команда запустит локальный сервер и откроет отчет в браузере.

2. В отчете Allure вы увидите:
   - Количество проведенных тестов.
   - Результаты тестирования: Успешное выполнение или ошибка.
   - Названия тестов.
   - Внутри каждого теста: 
     - приоритет.
     - описание.
     - шаги.
